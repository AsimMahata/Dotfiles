Technical Implementation Architecture

How this will be engineered in Python 3 + GTK 3 + GtkLayerShell adhering strictly to gtk.md.

Playbook: Plan
01. SwayNC Click-Catcher

100% Transparent Layer

The window anchors to all 4 screen edges on Layer.TOP. The root is a transparent Gtk.EventBox. Clicking anywhere outside the floating dock cards immediately terminates the process with Gtk.main_quit() — zero ghost windows or stuck input regions.

02. Parabolic Height Curve

Dynamic Scale & Curvature

A centered horizontal Gtk.Box with 5 to 7 visible cards. As the active index shifts, cards are dynamically assigned CSS classes or resized: Center = 280x175px (scale 1.15), Left/Right 1 = 220x138px, Edges = 170x106px.

03. 60fps Scroll & Matugen

Non-Blocking Interactions

Mouse wheel events are captured with Gdk.EventMask.SCROLL_MASK and throttled using GLib.timeout_add(16, ...) to guarantee silky 60fps animation. Matugen palette preview runs asynchronously in a worker thread without freezing the UI.
