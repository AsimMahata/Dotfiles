Waybar Scripts Folder Grouping Options

Clean up the flat 13 files in ~/.config/waybar/scripts/.

Architectural Decision
Option 1 Recommended

Role-Based Architecture

Separated by role: modals/ (UI), launchers/ (toggles), modules/ (feeds).

scripts/ ├── launch.sh ├── toggle.sh ├── modals/ │ ├── quick-slider.py │ ├── quick-connectivity.py │ ├── quick-hardware.py │ └── power-profile-osd.py ├── launchers/ │ ├── volume-toggle.sh │ ├── brightness-toggle.sh │ ├── connectivity-toggle.sh │ └── hardware-toggle.sh └── modules/ ├── dynamic-island.py └── power-profile-status.sh
✓ Cleanest root (only 2 commands)
Option 2 Feature Domain

Feature-Domain

Colocated by feature: each domain has both its modal and launcher together.

scripts/ ├── launch.sh ├── toggle.sh ├── hardware/ │ ├── quick-hardware.py │ └── hardware-toggle.sh ├── connectivity/ │ ├── quick-connectivity.py │ └── connectivity-toggle.sh ├── power/ │ ├── power-profile-osd.py │ └── power-profile-cycle.sh └── island/ └── dynamic-island.py
✓ All files for 1 feature in 1 folder
Option 3 Minimalist

Minimalist Hybrid

Leave all *.sh in root, move only Python modals & feeds.

scripts/ ├── [all *.sh launchers stay here] ├── modals/ │ ├── quick-slider.py │ ├── quick-connectivity.py │ └── quick-hardware.py └── modules/ ├── dynamic-island.py └── power-profile-status.sh
✓ Smallest path changes in config
